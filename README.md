# mvts-backend-services
Arquitecto Backend (El "Cerebro" del Sistema) MVTS

Herramientas: Java (Spring Boot), NetBeans, MongoDB (Atlas) y MySQL.

Misión: Esta persona construirá la API. Su trabajo es conectar Spring Boot a RabbitMQ para "atrapar" los mensajes que envía el de Python, y luego guardarlos en MongoDB. También creará las rutas REST (ej. GET /api/vehiculos) para que el Frontend las consuma.

Hito de éxito: Recibir un mensaje de RabbitMQ y que aparezca guardado en la interfaz de MongoDB Compass.

Ventaja: Ideal para quien tenga más lógica de negocio y domine la programación orientada a objetos en Java.
